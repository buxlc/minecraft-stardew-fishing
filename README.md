# 星露渔歌 StardewFishing 1.0.0

在原版抛竿和收竿流程上增加鱼类图鉴、鱼王、鱼饵、鱼竿改造、烤鱼与金币售卖。默认包含 25 种普通鱼和 5 种鱼王。适用于 Spigot 1.21.4 / Java 21。

## 安装教程

1. 将 `dist/StardewFishing-1.0.0.jar` 放入服务器 `plugins` 文件夹。
2. 售卖、购买吊具和付费改造需要 **Vault + 支持 Vault 的经济插件**，例如服务器现有的 EssentialsX Economy。插件不自建另一套金币账户。
3. 完整重启服务器。在游戏内输入 `/sfish`，即可打开钓鱼手册。
4. 首次启动生成 `plugins/StardewFishing/config.yml` 和 `fish.yml`。修改后使用 `/sfish reload`；重载会关闭当前菜单并清除正在使用的自定义浮漂。

没有经济服务时，钓鱼、鱼饵合成、图鉴、烤制、食用、镶嵌和拆卸已有吊具仍可使用。首次钓鱼会为普通鱼竿写入识别信息；普通玩家默认拥有使用权限。

## 玩家功能参考

| 命令 | 功能 |
| --- | --- |
| `/sfish` | 钓鱼手册首页 |
| `/sfish book` | 全部鱼类图鉴，含出没条件、长度与价格范围 |
| `/sfish caught` | 个人已钓获图鉴，含数量、首次钓获日期、最长纪录 |
| `/sfish kings` | 鱼王图鉴、解锁状态与个人冷却 |
| `/sfish sell` | 售卖主手整组鱼、背包普通鱼或单独确认出售鱼王 |
| `/sfish rod` | 改造主手鱼竿、购买/镶嵌/拆卸吊具 |
| `/sfish bait` | 无序合成配方与钓鱼指南 |
| `/sfish toggle` | 开关特色钓鱼；关闭后恢复原版钓鱼规则 |

别名为 `/fish`、`/fishing`、`/diaoyu`。如果与其他插件的别名冲突，使用唯一主命令 `/sfish`。

生鱼与烤鱼的名称和 Lore 显示鱼种、品质、实际长度、售价、出没区域、食用增益及烤制状态。售卖、食用、赠送或烤制鱼不会清除已经解锁的图鉴；收到他人的鱼或管理员发放的鱼不会解锁图鉴，必须自己成功钓获。

背包满时，渔获和购买物品会落在玩家脚边，限定玩家拾取并具有实体无敌保护，避免在岩浆旁立即被烧毁；请在原版物品消失时间前拾取。

## 默认经济与难度参考

- 普通鱼生鲜价格 **18～90金币**，烤制后 **27～135金币**。同种鱼越长越贵，长度以0.1cm记录；短鱼比长鱼常见。
- 鱼王生鲜价格 **1200～1950金币**，烤制后 **1800～2925金币**。所有价格、长度和权重可在 `fish.yml` 调整，烤制倍率在 `config.yml` 调整。
- 基础鱼王概率为符合条件的鱼种抽取的 **0.15%**；叠加鱼饵、吊具、精工改造、海之眷顾和幸运效果后，默认最高 **0.45%**。鱼王独立抽取，不会因为某个渔区普通鱼少而变成常见渔获。
- 每种鱼王对每位玩家独立计算 **24小时真实时间冷却**，退出和重启仍保留。鱼王另需满足鱼饵等级、群系、时间、天气或高度条件。
- 成功收获时有 **6%** 概率改为获得一个鱼饵；此时不消耗玩家鱼饵，也不解锁鱼类图鉴。鱼王概率仅适用于其余实际鱼种抽取。
- 默认珍稀加成上限为+200%。面板的“珍稀加成”作用于抽取权重与鱼王概率，不表示直接增加同等百分点的出货率；“长度分布加成”提高长度区间的位置，不会超过物种最大长度。

| 鱼王 | ID | 出没要求 | 生鲜价格 |
| --- | --- | --- | --- |
| 苍流之王 | `river_king` | 河流、雨天、3级以上鱼饵 | 1200～1650 |
| 深蓝君主 | `ocean_king` | 深海、夜晚、3级以上鱼饵 | 1300～1800 |
| 霜冠鱼王 | `glacier_king` | 冰海、夜晚、4级鱼饵 | 1250～1750 |
| 地心琉璃王 | `cave_king` | 主世界地下水域、Y≤0、4级鱼饵 | 1250～1750 |
| 炎狱帝王 | `inferno_king` | 地狱岩浆、Y≤40、4级鱼饵、熔岩吊具 | 1400～1950 |

夜晚范围以各鱼种的 MC 时间配置为准。默认鱼池覆盖主世界水域与地狱岩浆；末地和地狱水池没有默认鱼种，可添加对应鱼池或关闭特色钓鱼使用原版规则。

## 鱼竿工坊参考

在主手拿好要操作的鱼竿后打开工坊。每根鱼竿有一个吊具槽，可同时保留精工改造等级和原有附魔。左键吊具图标消耗背包内的一个对应吊具并镶嵌，右键购买一个；更换吊具和拆卸均免费，旧吊具返还背包，操作前需有一个空背包格。

| 吊具 | ID | 默认价格 | 效果 |
| --- | --- | --- | --- |
| 铜制吊具 | `copper` | 120 | 珍稀加成+15% |
| 寻珍吊具 | `treasure` | 450 | 珍稀加成+45%，长度分布+2% |
| 量鱼吊具 | `quality` | 380 | 珍稀加成+15%，长度分布+12% |
| 熔岩吊具 | `lava` | 800 | 解锁岩浆钓鱼，珍稀加成+10% |

精工改造按次从0级提升到1/2/3级，费用分别为250/750/1800。对应**总加成**为珍稀+10%/+20%/+35%，长度分布+2%/+5%/+8%，不是将每一级重复相加。实际等级与吊具信息均写入鱼竿 Lore。

熔岩吊具需占用该唯一吊具槽。将浮漂投到地狱敞开的岩浆表面，默认等待12～30秒，饵钓附魔可缩短等待；看到咬钩提示后默认有3.5秒收竿窗口。提前收竿没有渔获，超时会等待下一次咬钩。岩浆仍使用普通的咬钩与右键收竿操作。

改造或切换钓鱼功能会清除当前浮漂；中途换竿、换配件、切换手持槽、离开世界、退出或死亡也会结束本次施钓，避免旧配件加成残留。改造竿和已镶嵌竿不能作为工作台或自动合成器的消耗材料；可使用铁砧按原版方式修复和附魔。

## 鱼饵、烤制与食用参考

鱼饵放在背包储物格中即可，不需装到竿上。每次成功钓到鱼会自动选择当时背包中**最高等级**鱼饵，消耗一个；不使用副手槽中的鱼饵。无鱼饵也能钓普通鱼，鱼王需要其定义的最低等级。鱼饵等级按 `baits` 中的配置顺序依次为1～4。

| 等级 | 鱼饵 / ID | 无序合成材料 | 产量 | 珍稀加成 |
| --- | --- | --- | --- | --- |
| 1 | 蚯蚓 / `basic` | 小麦 + 腐肉 | 6 | +10% |
| 2 | 鲜虾 / `fine` | 插件蚯蚓鱼饵 + 糖 + 干海带 | 3 | +30% |
| 3 | 珍珠 / `premium` | 插件鲜虾鱼饵 + 海晶砂粒 + 蜂蜜瓶 | 2 | +60% |
| 4 | 星辉 / `master` | 插件珍珠鱼饵 + 恶魂之泪 + 荧石粉 | 1 | +100% |

各材料分别放入一个合成格，位置不限。高级配方必须使用插件鱼饵，原版种子无效，自动合成器同样验证。钓到鱼饵时，四级鱼饵的条件概率分别为82%/15%/2.7%/0.3%，高级饵更难直接钓到。插件鱼饵不能作为原版种子种植或消耗在其他普通配方中。

所有自定义鱼均以原版鳕鱼或鲑鱼作为物品外观，无须资源包。可放入熔炉、烟熏炉或营火烤制，物种和长度会保留，售价固定乘以1.5，不会重复叠乘。**不同种类或不同长度的鱼请及时分批取走成品**：炉子输出槽已有不兼容鱼类时会停止本次烤制，避免把短鱼叠成高价长鱼。

食用可获得迅捷、急迫、夜视、幸运、水下呼吸、抗火、生命恢复或饱和中的一种，均为I级。默认普通生鱼增益8秒、普通烤鱼25秒、鱼王45秒，同玩家增益触发冷却30秒；饱和只作用一个瞬间，避免持续大量补充饱食度。原版同种更强效果由服务端原版规则处理。

## 管理配置参考

`config.yml` 管理钓鱼开关默认值、禁用世界、岩浆等待、鱼王概率与个人冷却、烤制倍率、食用增益时长、鱼饵/吊具/改造数值和配方。`fish.yml` 管理鱼种；鱼种ID不可重复，建议长期保留已有ID、外观材料和长度范围，以免旧物品变为不可识别状态。更改价格会即时影响真实成交价，旧物品的 Lore 文字不会自动刷新。

鱼种可通过 `environments`、`biomes`、`worlds`、`regions`、`min-y/max-y`、`start-time/end-time`、`weather` 和 `min-bait` 联合筛选。空的群系、世界或渔区列表表示不限制；多个限制取交集。时间支持跨午夜，天气值为 `ANY/CLEAR/RAIN/THUNDER`；群系使用 Spigot 1.21.4 的大写名称，环境使用 `NORMAL/NETHER/THE_END`。水域判断以浮漂位置为准。

坐标渔区示例，在 `config.yml` 的 `regions` 下配置后，由鱼种通过 `regions: [spawn_lake]` 引用。重叠区域只使用 `priority` 最高的区域，可用于主城湖、海港、活动渔区等。

```yaml
regions:
  spawn_lake:
    name: 主城湖
    world: world
    min: [-120, -64, -120]
    max: [120, 320, 120]
    priority: 10
```

| 权限 | 默认 | 作用 |
| --- | --- | --- |
| `stardewfishing.use` | 所有人 | 钓鱼与玩家菜单 |
| `stardewfishing.admin` | OP | 重载和发放物品 |

管理员命令：

```text
/sfish reload
/sfish give <在线玩家> fish <鱼种ID> <数量1~64> [鱼长cm] [cooked]
/sfish give <在线玩家> bait <鱼饵ID> <数量1~64>
/sfish give <在线玩家> tackle <吊具ID> <数量1~64>
```

例如 `/sfish give Steve fish river_king 1 150 cooked` 发一条150cm的烤制苍流之王，`/sfish give Steve tackle lava 1` 发一个熔岩吊具。这些命令不会增加图鉴记录。

玩家数据按UUID保存在 `players/<UUID>.yml`，钓获时先原子保存图鉴与鱼王冷却，再发放物品，写入失败不会消耗鱼饵或发奖。配置无效时重载会保留之前的设置；玩家数据损坏时停止该玩家相关操作并保留原文件，避免将损坏资料重置覆盖。

请将整个 `plugins/StardewFishing` 文件夹一起备份，特别是 **`item-key.bin`**。该密钥验证鱼、鱼饵、吊具及鱼竿改造信息，防止仅修改名称/Lore伪造商品；丢失密钥会导致旧插件物品不能认证。不要在运行中删除密钥，也不要将密钥发给玩家。此机制不会限制管理员权限或创造模式本身的复制能力。

## 构建与验证

需要 Java 21 和 Maven。运行 `./build.ps1` 编译，再运行 `./package.ps1` 把 JAR、源码 ZIP 和 SHA256 清单放入 `dist/`；也可以用 `./package.ps1 -Build` 一次完成。脚本从 `JAVA_HOME` 和 `PATH` 查找已有工具，默认将依赖缓存和临时文件放在 F 盘，可通过参数调整。Spigot 和 Vault 只用于编译，不会打进插件 JAR。

测试覆盖与实服待验项目见 [VERIFICATION.md](VERIFICATION.md)。本版本尚未在真实客户端验证岩浆浮漂物理表现、图形界面和第三方保护/经济插件组合；部署前先在测试服按验证文档检查。
